# 生成AI用語ドリル

生成AIパスポート試験の用語を覚える静的サイトです。`python build.py` を実行すると `docs/` に全ページが書き出され、そのまま GitHub Pages で公開できます。サーバもデータベースも要りません。

姉妹サイト「クラウド用語ドリル」（`cloud-drill`）の仕組みをもとに作っています。

- 公開URL（予定）: https://genai.yogo-drill.com/

## フォルダの中身

| パス | 内容 | 編集するか |
|---|---|---|
| `config.json` | サイト名・公開URL・姉妹サイト・運営者・アクセス解析・広告の設定 | する |
| `data/make_terms.py` | 用語の元データ。実行すると `data/terms.json` を作る | する |
| `data/terms.json` | 用語データ（`make_terms.py` が作る） | しない |
| `build.py` | ページを生成するスクリプト。分野（`FIELDS`）、ミニテストの問題数（`TEST_COUNTS`）、運営者情報・プライバシーポリシーの文面もここにある | 文面を変えるとき |
| `static/assets/` | CSS と JavaScript。`app.js` ホームの単語帳、`drill.js` ミニテストと略語クイズ、`term.js` 用語ページの確認問題 | 見た目や機能を変えるとき |
| `docs/` | 生成されたサイト。**直接編集しない**（ビルドのたびに作り直される） | しない |

## 普段の作業

```powershell
cd "C:\Users\admin\Desktop\genai-drill"
python data/make_terms.py             # 用語を直したとき
python build.py                       # docs/ を作り直す
python -m http.server 8000 -d docs    # http://localhost:8000 で確認（Ctrl+C で終了）
```

## 用語を追加・修正する

`data/make_terms.py` の `TERMS` に、`(分野, 小分類, 用語, 正式名, 説明)` の形で書きます。

- 分野は `A`（AIの基礎と歴史）/ `G`（生成AI）/ `E`（AIエージェント）/ `R`（リスク予防・倫理・ガバナンス）/ `P`（実践と活用）。シラバスの5つの章
- id は並び順で付く。**公開後は、新しい用語をリストの最後に足す**（途中に足したり消したりすると、ページの URL `terms/0001.html` がずれる）
- 正式名を書くと、略語クイズと略語の早見表に入る
- 出題範囲は、試験の実施団体（GUGA）のシラバス（2027年2月試験から適用）の詳細キーワードに合わせる。シラバスは毎年のように改訂されるので、改訂のたびに見直す。商品やモデルの名前・バージョンは書かない

## 学習の記録

進み具合はブラウザの localStorage に保存します。FE・ITパスポートのサイトと同じ `yuki-fe.github.io` の上で動くので、保存の名前は `genai-drill-` で始めています。

## 名前について

「生成AIパスポート」は試験の実施団体の資格の名前なので、サイトの名前には入れず、「生成AIパスポート試験の用語」と事実として文字で書くだけにしています。全ページの下に、実施団体とは関係がないことの注意書きを出しています。
