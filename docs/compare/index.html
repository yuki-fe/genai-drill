似た用語の違い生成AIパスポート試験でまぎらわしい用語 15組

似た用語は、違いを言えるようにしておくと得点につながります。2つ（3つ）の用語を表で並べて、どこが違うかを確かめましょう。

  • AI・機械学習・ディープラーニングの違い

    AIがいちばん大きな枠で、その中に機械学習、さらにその中にディープラーニングがある「入れ子」の関係です。今の生成AIは、ディープラーニングを土台にしています。

  • 教師あり学習・教師なし学習・強化学習の違い

    正解付きのデータで学ぶのが教師あり学習、正解なしでデータのまとまりを見つけるのが教師なし学習、試行錯誤して報酬が多くなる行動を学ぶのが強化学習です。

  • 分類と回帰の違い

    どちらも教師あり学習で解く問題です。データがどのグループに入るかを当てるのが分類、売上や気温のような数の値を予測するのが回帰です。

  • 転移学習とファインチューニングの違い

    どちらも学習済みモデルを生かして、一から学習せずに新しい目的に合わせる方法です。よくある説明では、学習済みの部分を固定して付け足した部分だけ学ぶのが転移学習、学習済みの部分の重みも調整し直すのがファインチューニングです。

  • CNN・RNN・Transformerの違い

    CNN は画像、RNN は文章や音声のような順番のあるデータを扱うのが得意なネットワークです。Transformer は Attention を中心にした仕組みで、並列に計算でき、今の LLM の土台になっています。

  • GAN・VAE・拡散モデルの違い

    どれも新しいデータを作る生成モデルです。GAN は2つのネットワークを競わせ、VAE はデータを潜在ベクトルに縮めてから作り直し、拡散モデルはノイズを少しずつ取り除いてデータを作ります。

  • RAGとファインチューニングの違い

    RAG はモデルはそのままで、質問のたびに関係する文書を検索して、その内容をもとに答えさせる方法です。ファインチューニングは、追加の学習でモデルそのもの（重み）を変える方法です。

  • TemperatureとTop-pの違い

    どちらも、次のトークンの選び方を調整する生成パラメータです。Temperature は確率の差の付け方を変え、Top-p は選ぶ候補の範囲をしぼります。

  • Zero-ShotとFew-Shotプロンプティングの違い

    Zero-Shot は例を示さずに指示だけで答えさせる方法、Few-Shot はいくつかの例（入力と出力の見本）を示してから答えさせる方法です。

  • ワークフロー型エージェントと自律型エージェントの違い

    ワークフロー型は人があらかじめ決めた手順どおりに動き、自律型は手順そのものを自分で考えて決めます。動きの予測しやすさと、柔軟さのどちらを取るかの違いです。

  • Function Calling・MCP・A2Aの違い

    Function Calling は生成AIが外部のツールを呼び出して使う仕組み、MCP は AI と外部のツールやデータをつなぐ共通の決まり、A2A はエージェントどうしが連携するための決まりです。

  • 匿名加工情報と仮名加工情報の違い

    匿名加工情報は、特定の個人を識別できず、元にも戻せないように加工した情報です。仮名加工情報は、ほかの情報と照らし合わせなければ個人を識別できないように加工した情報で、主に社内の分析に使います。

  • 著作者人格権と複製権・翻案権の違い

    著作者人格権は作者の気持ちや名誉を守る権利で、人に譲れません。複製権・翻案権は、作品から利益を得る面を守る著作権（財産権）の一部で、人に譲ることができます。

  • エコーチェンバーとフィルターバブルの違い

    エコーチェンバーは、似た意見の人どうしが集まり、同じ意見が響き合って強まる現象です。フィルターバブルは、検索やおすすめの仕組みによって、自分の好みに合う情報ばかりに囲まれることです。

  • シャドーAIとシャドーITの違い

    シャドーITは、会社が認めていないIT機器やサービスを従業員が業務で使うことです。シャドーAIは、その中でも会社が認めていない生成AIのツールを勝手に使うことを指します。
