ワークフロー型エージェントと自律型エージェントの違い

ワークフロー型は人があらかじめ決めた手順どおりに動き、自律型は手順そのものを自分で考えて決めます。動きの予測しやすさと、柔軟さのどちらを取るかの違いです。

表で比べる

観点ワークフロー型エージェント自律型エージェント
手順を決めるのは人（あらかじめ設計する）エージェント自身
動きの予測しやすいしにくい
向いている作業手順が決まっている定型の業務進め方が決まっていない調査や、複雑な作業
気をつけること想定していない場面に対応しにくい想定外の動き。権限をしぼり、大事な操作の前に人が確認する

見分けるポイント

  • 「あらかじめ決めた手順」「予測しやすい」が出てきたらワークフロー型
  • 「自分で手順を考える」「状況に応じて進め方を変える」が出てきたら自律型
  • どこまで任せるかの度合いを自律性のレベルという
  • 自律性が高いほど、Human-in-the-Loop や最小権限の原則などの安全の仕組みが大切になる

試験での出され方

業務の例を読んで、どちらの型が向いているかを選ぶ問題や、自律型を使うときに必要な対策を問う問題が考えられます。

それぞれの用語

  • ワークフロー型エージェント

    人があらかじめ決めた手順（ワークフロー）に沿って動くエージェント。動きが予測しやすく、管理しやすい。

  • 自律型エージェント

    手順を自分で考えて決め、状況に応じて進め方を変えるエージェント。柔軟だが、想定外の動きへの注意が必要。
