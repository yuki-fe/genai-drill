CNN・RNN・Transformerの違い

CNN は画像、RNN は文章や音声のような順番のあるデータを扱うのが得意なネットワークです。Transformer は Attention を中心にした仕組みで、並列に計算でき、今の LLM の土台になっています。

表で比べる

観点CNNRNNTransformer
得意なデータ画像文章・音声などの順番のあるデータ文章など（画像などにも使われる）
仕組みの中心畳み込み（小さな範囲ごとに特徴をとらえる）前の時点の情報を次に引き継ぐAttention（入力のどこに注目するかを重み付けする）
計算のしかた範囲ごとの計算をまとめて行える1つずつ順番に計算するまとめて並列に計算できる
長い文章の扱い（主に画像に使う）遠く離れた情報を覚えておきにくい（LSTM で改良）遠く離れた言葉の関係もとらえやすい

見分けるポイント

  • 「畳み込み」「画像の認識」が出てきたら CNN
  • 「前の時点の情報を引き継ぐ」「シーケンスデータ」が出てきたら RNN。長い順番のデータでも覚えておけるように改良したのが LSTM
  • 「Attention」「並列に計算」「LLM の土台」が出てきたら Transformer
  • Transformer の中で、同じ文章の単語どうしの関係を計算するのが Self-Attention

試験での出され方

仕組みの説明から、どのモデルかを選ぶ問題が考えられます。「得意なデータ」と「仕組みのキーワード」をセットで覚えておきましょう。

それぞれの用語

  • CNN（畳み込みニューラルネットワーク）

    画像の小さな範囲ごとに特徴をとらえる「畳み込み」を使うネットワーク。画像の認識（コンピュータビジョン）が得意。

  • RNN（再帰型ニューラルネットワーク）

    前の時点の情報を次に引き継ぎながら処理するネットワーク。文章や音声などの順番のあるデータ（シーケンスデータ）を扱う。

  • Transformer

    Attention を中心にした、文章などを処理するモデルの仕組み。並列に計算でき、遠く離れた言葉の関係（長距離依存）もとらえやすい。今の LLM の土台。
