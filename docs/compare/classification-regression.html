分類と回帰の違い

どちらも教師あり学習で解く問題です。データがどのグループに入るかを当てるのが分類、売上や気温のような数の値を予測するのが回帰です。

表で比べる

観点分類回帰
答えの形グループの名前（迷惑メールか・そうでないか など）数の値（売上・気温 など）
例画像に写っている動物を当てる、口コミが良い評価か悪い評価かを判定する明日の気温を予測する、来月の売上を予測する
種類2つに分ける二値分類と、3つ以上に分ける多値分類数の大きさそのものを予測する
良さの見方の例正解率（予測が当たった割合）予測と実際の値とのずれの大きさ

見分けるポイント

  • 答えが「どれか」なら分類、「いくつ」なら回帰
  • どちらも正解付きのデータで学ぶ教師あり学習
  • 正解のないデータをグループに分けるのはクラスタリング（教師なし学習）。分類とは別もの

試験での出され方

「明日の降水量を予測する」「メールが迷惑メールかを判定する」のような例が、分類と回帰のどちらに当たるかを見分けられるようにしておきましょう。分類とクラスタリングの取り違えにも注意します。

それぞれの用語

  • 分類

    データがどのグループに入るかを当てる問題。2つに分ける二値分類と、3つ以上に分ける多値分類がある。

  • 回帰

    売上や気温のような、数の値を予測する問題。
