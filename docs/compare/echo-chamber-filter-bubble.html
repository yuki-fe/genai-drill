エコーチェンバーとフィルターバブルの違い

エコーチェンバーは、似た意見の人どうしが集まり、同じ意見が響き合って強まる現象です。フィルターバブルは、検索やおすすめの仕組みによって、自分の好みに合う情報ばかりに囲まれることです。

表で比べる

観点エコーチェンバーフィルターバブル
起こるきっかけ人どうしのつながり（似た意見の人が集まる）システムの仕組み（検索やおすすめのアルゴリズム）
起こること同じ意見ばかりがくり返され、正しいという思い込みが強まる好みに合わない情報が見えにくくなる
名前のたとえ声が響き合う部屋（反響室）泡（バブル）の中に閉じこもる

見分けるポイント

  • 「似た意見の人が集まる」「響き合う」が出てきたらエコーチェンバー
  • 「アルゴリズム」「好みに合わせて表示」「泡」が出てきたらフィルターバブル
  • どちらも考えがかたよる原因になる。一次情報や、ちがう立場の情報にもあたって確かめる

試験での出され方

SNS や検索の場面の説明から、どちらの現象かを選ぶ問題が考えられます。きっかけが「人の集まり」か「仕組み（アルゴリズム）」かで見分けましょう。

それぞれの用語

  • エコーチェンバー

    似た意見の人どうしで集まり、同じ意見ばかりが響き合って強まる現象。

  • フィルターバブル

    検索やおすすめの仕組みで、自分の好みに合う情報ばかりに囲まれ、ほかの見方が見えにくくなること。
