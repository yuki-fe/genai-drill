教師あり学習・教師なし学習・強化学習の違い

正解付きのデータで学ぶのが教師あり学習、正解なしでデータのまとまりを見つけるのが教師なし学習、試行錯誤して報酬が多くなる行動を学ぶのが強化学習です。

表で比べる

観点教師あり学習教師なし学習強化学習
使うデータ入力と正解（ラベル）の組正解の付いていないデータ行動した結果として得られる報酬
学ぶこと入力から正解を当てる決まりデータの中の似たもののまとまりや特徴報酬が最も多くなる行動のしかた（方策）
代表的な使い方分類、回帰クラスタリング、次元削減ゲーム、ロボットの制御
例写真に写っているのが犬か猫かを当てる買い物の傾向が似た客をグループに分けるゲームで高い得点を取れる動き方を身につける

見分けるポイント

  • 「正解（ラベル）付き」「教師データ」が出てきたら教師あり学習
  • 「正解なし」「グループに分ける」「次元削減」が出てきたら教師なし学習
  • 「報酬」「試行錯誤」「行動」が出てきたら強化学習
  • 少しの正解付きデータと、たくさんの正解なしデータを組み合わせるのは半教師あり学習
  • LLM の学習で使う RLHF は、強化学習の考え方を使っている

試験での出され方

使い方の例を読んで、どの学習方法に当てはまるかを選ぶ問題が考えられます。「正解があるか」「報酬があるか」の2点を見ると見分けられます。

それぞれの用語

  • 教師あり学習

    正解（ラベル）付きのデータで学ぶ機械学習。分類や回帰に使う。

  • 教師なし学習

    正解の付いていないデータから、似たもののまとまりや特徴を見つける機械学習。クラスタリングや次元削減など。

  • 強化学習

    試行錯誤しながら、報酬が最も多くなる行動のしかたを学ぶ機械学習。ゲームやロボットの制御などに使う。
