Function Calling・MCP・A2Aの違い

Function Calling は生成AIが外部のツールを呼び出して使う仕組み、MCP は AI と外部のツールやデータをつなぐ共通の決まり、A2A はエージェントどうしが連携するための決まりです。

表で比べる

観点Function Calling（Tool Use）MCPA2A
つなぐもの生成AIと、関数・ツールAI と、外部のツール・データエージェントとエージェント
どんなものか生成AIが、決められた形でツールの呼び出しを出す仕組みツールやデータのつなぎ方をそろえた共通のプロトコルエージェントどうしが情報をやり取りするための共通のプロトコル
例天気を聞かれたら、天気を調べる関数を呼び出すMCPサーバーを通して、ファイルや社内のサービスを使う予約を受け持つエージェントが、支払いを受け持つエージェントに作業を頼む

見分けるポイント

  • 「AI が外部のツールを呼び出して使う」基本の仕組みは Function Calling（Tool Use）
  • 「AI とツール・データの接続をそろえる共通の決まり」「MCPサーバー」が出てきたら MCP
  • 「エージェントどうしの連携」が出てきたら A2A
  • どれも外部とつながるので、与える権限の管理が大切

試験での出され方

「異なるエージェントどうしを連携させる決まり」「AI と外部のツールをつなぐ方法をそろえる決まり」のような説明から、どの用語かを選ぶ問題が考えられます。何と何をつなぐかで見分けましょう。

それぞれの用語

  • Function Calling（Tool Use）

    生成AIが、決められた形で外部の関数やツール（検索・計算・API など）を呼び出して使う仕組み。

  • MCP（Model Context Protocol）

    AI と、外部のツールやデータをつなぐための共通の決まり（プロトコル）。MCP サーバーを通して、いろいろなサービスを同じ方法で使える。

  • A2A（Agent-to-Agent）

    異なるエージェントどうしが、情報をやり取りして連携するための決まり（プロトコル）。
